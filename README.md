# MovieAPP

WPF-приложение для просмотра списков фильмов с интеграцией Kinopoisk API Unofficial

## Функционал:

- Главная страница: список фильмов, сортировка, пагинация
- Избранное: локальное хранение, добавление/удаление
- Подробности фильма: описание, актёры, жанры, рейтинг

## Запуск приложения:

1. **Клоинровать репозиторий**
2. **Создайте файл конфигурации:**
   - Скопируйте `appsettings.example.json` → `appsettings.json`
   - Впишите свой API-ключ Кинопоиска:
     ```json
     {
       "KinopoiskApi": {
         "ApiKey": "ВАШ_КЛЮЧ",
         "BaseUrl": "https://kinopoiskapiunofficial.tech/api/v2.2/films/collections"
       }
     }
     ```
3. **Соберите и запустите проект**
